# TAR UMT Website AI Chatbot (RAG)

A RAG (Retrieval-Augmented Generation) chatbot that answers questions about **Tunku Abdul Rahman University of Management and Technology (TARUMT)** — powered by a local Phi-4 model, ChromaDB, and LangChain.

## Overview

This chatbot crawls and indexes the official TARUMT websites, then lets users ask natural language questions about programmes, admissions, facilities, campuses, and more. It does **not** call any external AI API — it runs entirely against a self-hosted Phi-4 endpoint on your local network.

**RAG Pipeline:**

```
Crawl TARUMT websites
        ↓
Scrape & clean page content
        ↓
Chunk by semantic meaning
        ↓
Embed & store in ChromaDB
        ↓
At query time: BM25 + Vector retrieval → Cross-encoder reranking → Phi-4 answer
```

## Prerequisites

- **Python 3.10+**
- A running **Phi-4 API server** on your local network (OpenAI-compatible `/v1/chat/completions` endpoint)
- Enough disk space for the ChromaDB index (~depends on how many pages are crawled)

> The chatbot will not work without the Phi-4 API. Update `PHI4_API_URL` in `src/config.py` to point to your server before running.

## Setup

**1. Clone the repository**

```bash
git clone https://github.com/mingshenchea-cmyk/TARUMT-AI-Chatbot
cd TARUMT-AI-Chatbot
```

**2. Create a virtual environment (recommended)**

```bash
python -m venv venv
venv\Scripts\activate      # Windows
# source venv/bin/activate  # macOS / Linux
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Set your Phi-4 API endpoint**

Open `src/config.py` and update:

```python
PHI4_API_URL = "http://<your-server-ip>:<port>/v1/chat/completions"
```

## Usage

All commands are run from inside the `src/` folder:

```bash
cd src
```

### Step 1 — Preview external domains *(optional)*

Runs a shallow crawl (depth 2) and lists any external domains found — useful to review before a full crawl.

```bash
python main.py crawl --check
```

### Step 2 — Full crawl

Crawls all 25 TARUMT domains and saves every discovered URL to `tarumt_urls.txt`.

```bash
python main.py crawl
```

> This can take a while depending on network speed.

### Step 3 — Ingest *(run once)*

Scrapes page content, chunks it by semantic meaning, and embeds everything into ChromaDB.

```bash
python main.py ingest
```

> This is the slowest step — embedding thousands of chunks takes several minutes on CPU.  
> You only need to re-run this if the website content has changed significantly.

### Step 4 — Chat

Starts an interactive chatbot session in your terminal.

```bash
python main.py chat
```

**Example:**

```
You: What courses does TARUMT offer?
Bot: TARUMT offers a wide range of programmes including Bachelor of Information Technology,
     Bachelor of Software Engineering, Diploma in Computer Science, and many more across
     faculties such as FOCS, FAFB, FSSH ...

You: How do I apply?
Bot: You can apply online at https://www.tarc.edu.my/admissions/ ...
```

Press `Ctrl+C` to exit.

## Configuration

All settings live in `src/config.py`:

| Setting | Default | Description |
|---|---|---|
| `BASES` | 25 TARUMT domains | List of websites to crawl and index |
| `EMBED_MODEL` | `all-MiniLM-L6-v2` | HuggingFace sentence embedding model |
| `RERANK_MODEL` | `ms-marco-MiniLM-L-6-v2` | Cross-encoder model for reranking results |
| `CHROMA_DIR` | `../tarumt_db` | Where ChromaDB stores the vector index |
| `CHROMA_COLLECTION` | `tarumt` | ChromaDB collection name |
| `URLS_FILE` | `../tarumt_urls.txt` | Output file for discovered URLs |
| `PHI4_API_URL` | `http://192.168.90.132:31419/...` | **Your** local Phi-4 API endpoint |
| `PHI4_MODEL` | `microsoft/Phi-4-multimodal-instruct` | Model name sent in the API request |

## How It Works

When you ask a question, the chatbot goes through three stages:

**1. Retrieval — finding relevant chunks**

Two retrievers run in parallel and their results are merged:
- **BM25** (keyword search) — good at matching exact terms like programme codes or names
- **Vector search** (ChromaDB) — good at matching meaning even when words differ

They are weighted 40% BM25 / 60% vector.

**2. Reranking — picking the best chunks**

A cross-encoder (`ms-marco-MiniLM-L-6-v2`) scores each retrieved chunk against your question and selects the top 3 most relevant ones. This is more accurate than vector similarity alone.

**3. Generation — producing the answer**

The top 3 chunks are sent as context to Phi-4, which is instructed to answer only from the provided context. If the answer is not in the context, it says so rather than hallucinating.

## Troubleshooting

**`Connection refused` when chatting**
> Your Phi-4 server is not running or the `PHI4_API_URL` in `config.py` is wrong. Verify the IP and port.

**`chromadb` errors on first chat**
> The `tarumt_db/` folder doesn't exist yet. Run `python main.py ingest` first.

**Chat loads very slowly on first run**
> The embedding and reranking models are being downloaded from HuggingFace on first use. Subsequent runs are fast.

**Answers feel outdated**
> Re-run `python main.py ingest` to re-crawl and re-index the latest content from the TARUMT websites.

## Customizing Models

The default models in `config.py` are **suggestions only** — you can swap them for any compatible alternative:

**Embedding model** (`EMBED_MODEL`):
- Current: `sentence-transformers/all-MiniLM-L6-v2` (lightweight, fast)
- Alternatives: Any model on [HuggingFace Sentence Transformers](https://huggingface.co/sentence-transformers)
  - `all-mpnet-base-v2` — better accuracy, slower
  - `paraphrase-multilingual-MiniLM-L12-v2` — for multilingual content

**Reranking model** (`RERANK_MODEL`):
- Current: `cross-encoder/ms-marco-MiniLM-L-6-v2` (fast, accurate)
- Alternatives: Any cross-encoder from HuggingFace
  - `cross-encoder/ms-marco-MiniLM-L-12-v2` — higher accuracy, slower
  - `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` — multilingual

**LLM API** (`PHI4_API_URL` / `PHI4_MODEL`):
- Current: Local Phi-4 endpoint
- Alternatives: Any OpenAI-compatible API
  - Local: Ollama, LM Studio, vLLM, text-generation-webui
  - Cloud: OpenAI, Anthropic (via adapters), Azure OpenAI

> Just update the values in `src/config.py` — no code changes needed.
